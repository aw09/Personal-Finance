Command catalog

Search is off for now, so this page lists every available command, its parameters, and a concrete example. All commands work in private 1:1 chats with the bot.

Onboarding & help​

CommandParametersWhat it doesExample
/startnoneSends the welcome message and checks bot permissions./start
/help [topic]topic options: wallet, add, recent, report, debtsShows inline help for a topic; plain /help shows buttons for all topics./help wallet
/categories listnoneShows your current category labels./categories list
/categories set LABEL,LABELlabels comma-separatedReplaces your labels with a custom list./categories set Dining Out,Groceries
/categories resetnoneRestores the default labels./categories reset

Quick capture & receipts​

Command / ShortcutParametersWhat it doesExample
Free text shorthandTYPE one of e/i/d/r, AMOUNT, DESCRIPTION, optional @wallet prefixFast entry for expense/income/debt/receivable without typing /add. Returns a detailed view with edit/delete buttons.@travel e taxi 75000 airport
/add [@wallet] TYPE AMOUNT DESCRIPTIONtype = expense, income, debt, or receivable; optional @wallet to target a non-default walletCreates a transaction with the given type and description, then shows full details and buttons./add @cash expense 125000 groceries
Receipt photoSend a photo with optional caption tokens: @wallet, installments=<n>, beneficiary=NameParses a receipt, saves the transaction, and updates the status message to show full details/buttons.Send photo with caption @cash installments=6 beneficiary=Travel

Amounts accept commas and decimals (e.g. 1,250 or 45.67). The bot normalises formatting automatically.

Transactions​

CommandParametersWhat it doesExample
/transaction IDid = transaction UUID shown in /recentShows full detail for a transaction with inline Edit and Delete buttons./transaction 123e4567-e89b-12d3-a456-426614174000
/transaction edit ID field=value ...field can be amount, description, category, date, wallet, wallet_id, type, currencyUpdates one or more fields directly from chat./transaction edit 123... amount=55000 description=Lunch

Wallets & balances​

All wallet subcommands also work with the alias /wallets.

CommandParametersWhat it doesExample
/wallet listnoneRefreshes balances and lists all wallets (default is tagged)./wallet list
`/wallet add NAME TYPE [currency=IDR] [limit=AMOUNT] [settlement=DAY] [kind=cc|paylater] [default=yesno]`TYPE = regular, investment, or credit; kind only for credit wallets (cc = monthly statement, paylater = BNPL-style); limit and settlement apply to credit wallets./wallet add Travel credit currency=IDR limit=25000000 settlement=25 kind=cc
`/wallet edit NAME [name=...] [currency=...] [limit=...] [settlement=DAY] [kind=cc|paylater] [default=yesno]`Updates the specified fields for a wallet./wallet edit Travel settlement=20 limit=30000000
/wallet default NAMEnameSets the default wallet for future entries./wallet default Main Wallet
/wallet transfer AMOUNT FROM TO [note=...]amount numeric; from/to are wallet names or @wallet hintsMoves funds between wallets and records matching transactions./wallet transfer 200000 @cash @travel note=top-up
/wallet adjust WALLET TARGET_BALANCE [desc=...] [date=YYYY-MM-DD]target_balance is the desired ending balanceRecords an adjustment transaction to reach the target balance./wallet adjust @cash 2500 desc=Manual adjustment date=2025-11-01
/wallet delete NAME confirm=yesconfirm=yes required; cannot delete the default walletDeletes a wallet; transactions remain but lose the wallet link./wallet delete OldWallet confirm=yes
/wallet investment roe WALLET [start=YYYY-MM-DD] [end=YYYY-MM-DD]wallet must be an investment wallet; optional date rangeCalculates simple return on equity for an investment wallet./wallet investment roe @invest start=2024-01-01 end=2024-12-31

Credit tools​

CommandParametersWhat it doesExample
/wallet credit purchase WALLET AMOUNT [installments=3] [beneficiary=Name] [desc=...]wallet must be credit; installments splits the purchase; beneficiary tags who it was forRecords a credit card/paylater purchase and creates an installment schedule./wallet credit purchase @card 250000 installments=6 beneficiary=Travel desc=Flight
/wallet credit repay WALLET AMOUNT [from=@wallet] [beneficiary=Name] [desc=...]wallet credit wallet being repaid; optional from source walletApplies a repayment and can pull cash from another wallet./wallet credit repay @card 500000 from=@cash desc=Bill payment
/wallet credit statement WALLET [reference=YYYY-MM-DD]reference date overrides "today" for the statement windowShows the upcoming settlement amount and due installments./wallet credit statement @card reference=2025-12-02
/lendcredit CREDIT_WALLET NAME AMOUNT [installments=3] [desc=...] [note=...] [beneficiary=...]Combines a credit purchase and a receivable in one command; name is who owes you; installments applies to the credit sideCreates both the card purchase and the receivable schedule at once./lendcredit @card IntegrationFriend 40000 installments=3 desc=Loan note=from card

Debts & repayments​

CommandParametersWhat it doesExample
/lend NAME AMOUNT [note]name = who owes you; note optionalCreates a receivable debt with a single installment./lend Alice 150000 note=Taxi
/repay NAME AMOUNT [note] [all]Applies a payment to the next unpaid installments for that person; add all to pay everything due./repay Alice 50000 note=Partial
/owed [name]Optional name filterShows outstanding receivables with per-loan breakdowns and delete buttons./owed Alice

History & reports​

CommandParametersWhat it doesExample
/recent [@wallet] [limit=TOTAL] [per=PAGE] [since=YYYY-MM-DD] [category=Name]limit total rows to fetch; per page size; optional wallet/category filtersLists transactions with inline pagination and detail buttons./recent @cash limit=10 per=5 since=2025-11-01
/report RANGErange options: today, yesterday, mtd, ytd, last 7 days, last 3 months, last year, etc.Summarises totals by type and currency for the chosen range./report last 7 days
